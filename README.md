# おとつみき — みんなの作曲アプリ

マス目に音をならべて、だれでもかんたんに作曲できるブラウザ用の音楽アプリです。
インストール不要で、`index.html` をブラウザで開くだけで動きます（タブレット対応）。

## できること
- 🎵 **メロディ**：マス目をクリックで音を置く／ドラッグで長さ・高さを変える。音の色は音の高さごとに決まっています
- 🎹 **コード伴奏**：小節ごとにコードを選ぶだけで伴奏（じゃーん・拍ごと・分散和音・ワルツ・マーチ）
- 🥁 **リズム**：打楽器14種（和太鼓・拍子木・鈴・カスタネット・トライアングルなど）。強弱つき。お手本リズムあり
- 🎻 **楽器16種**：ピアノ、鍵盤ハーモニカ、リコーダー、木琴、鉄琴、琴、ギター、オルガン、ストリングス など
- 🎼 **音階10種**：長音階・短音階・ヨナ抜き・民謡・都節・律・沖縄・ブルース・全音音階・半音すべて
- 🔑 調（12調）・拍子（2/4・3/4・4/4・6/8）・小節数（1〜64）・16分音符まで
- 🎲 **おまかせ作曲**（音階とコードに合わせて自動でメロディを作る）
- 🔁 **輪唱づくり**（メロディを何小節かずらして別パートへ写す）、移調、小節コピー
- 音名表示の切り替え（ドレミ／移動ド／CDE／ハニホ）、ほかのパートを点線で重ねて表示
- テンポ、メトロノーム、部分くりかえし、ひびき（リバーブ）、スウィング
- 元に戻す／やり直す、自動の一時保存
- 💾 ブラウザ内に保存、曲ファイル（.json）の書き出し・読み込み
- 🔗 **共有URL**（URLを送るだけで同じ曲を開ける）
- 🔊 WAV（音声）・MIDI 書き出し、🖨 印刷

## 使い方
`index.html` をダブルクリックしてブラウザ（Chrome / Edge / Safari など）で開きます。
画面右上の「❓ 使い方」にくわしい説明があります。

## ファイル
- `index.html` … 画面
- `css/style.css` … 見た目
- `js/sound.js` … 楽器の音を作る部分
- `js/app.js` … アプリの動き
