# おとつみき — みんなの作曲アプリ

マス目に音をならべて、だれでもかんたんに作曲できるブラウザ用の音楽アプリです。
インストール不要で、`index.html` をブラウザで開くだけで動きます（パソコン・タブレット・スマホ対応）。
スマホでは専用の画面になります（下のタブで切りかえ、指2本でスクロール、画面の鍵盤で入力）。

## 画面のしくみ
- **ミニディスプレイ**：曲名・いまの位置・調・拍子・テンポ。音を置くと五線の音符と音名が出ます
- **キャンバス**：曲全体の地図（トラック × 小節）。ドラッグで小節コピー、🗑で消去、小節の挿入・削除、テンポ変化
- **オトグラフ**：音を置くマス目。ループバーでくりかえし範囲を指定
- **トラック**：最大8パート。楽器、音量、消音、ソロ、並べかえ、複製

## できること
| 分類 | 内容 |
|---|---|
| 入力 | クリックで置く・ドラッグでのばす／動かす、和音、おたまチョップ（全音符〜32分音符・8分/16分3連符）、パソコンのキーボードやMIDI鍵盤で1音ずつ入力 |
| 楽器 | 64種（鍵盤・オーケストラ・和楽器・ギター/ベース・シンセ・その他）。うち51種は**本物の楽器の録音**と電子音を切りかえられる |
| 打楽器 | 7キット・56音（うち34音は本物の録音）（ドラム、音楽室、和太鼓・和楽器、パーカッション×2、EDM、効果音）、強弱つき、お手本リズム9種 |
| ルール | 12調、11音階（長調・短調・ヨナ抜き・民謡・都節・律・沖縄など）、拍子 1〜6 / 2・4・8、テンポ30〜240＋タップ入力、曲の途中のテンポ変化、スウィング |
| 作曲支援 | コード伴奏（6パターン）、🎲おまかせ作曲、輪唱づくり、音の移動（範囲指定可）、ほかのパートの重ね表示 |
| パレット | ミキサー、3バンドイコライザー、リバーブ、メトロノームの音色・音量、エフェクトパッド（ローパス／ハイパス／スタッター／ディレイ／リバーブ／デシメーター） |
| 楽譜で編集 | 五線譜の上で直接書く（Flat のようなクリック入力・キーボード入力・選択・コピー/貼りつけ）、アーティキュレーション・強弱記号・クレッシェンド・スラー・タイ（再生にも反映）、くり返し記号・1番/2番かっこ（再生もくり返す）、歌詞、コードネーム、再生中に音符が光る |
| 楽譜 | 五線譜を自動作成（調号・拍子・連桁・タイ・3連符・コードネーム）、歌詞、ドレミをふる、作詞・作曲者、音部記号、リズム譜、印刷・PDF・PNG・SVG・**MusicXML**書き出し、編集中の楽譜を下に表示 |
| 保存・共有 | MusicXML読み込み（Flat・MuseScore などの楽譜）、自動一時保存、ブラウザ内保存、曲ファイル書き出し・読み込み、MIDI読み込み、共有URL、WAV・MIDI書き出し |
| 先生用 | トラックのロック、ルール変更・トラック追加・消音・おまかせ作曲の制限、暗証番号 |
| その他 | 元に戻す・進む、履歴一覧、音名表示切りかえ（ドレミ／移動ド／CDE／ハニホ、♯/♭）、ダークモード |

## ファイル
- `index.html` … 画面
- `css/style.css` … 見た目
- `js/sound.js` … 楽器・打楽器の音を作る部分
- `js/notation.js` … 楽譜（五線譜）を作る部分
- `js/musicxml.js` … MusicXML（.musicxml / .mxl）の読み込み
- `js/app.js` … アプリの動き
- `samples/` … 本物の楽器の録音（必要なときだけ読み込みます）
- `tools/build_samples.py` … 録音を作り直すスクリプト
- `tools/audit.js` … 検証スクリプト（結果は `docs/検証レポート.md`）

## 録音について
楽器の録音は [FluidR3 GM サウンドフォント](https://github.com/gleitz/midi-js-soundfonts)（Frank Wen 作）を使っています。
